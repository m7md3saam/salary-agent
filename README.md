# مساعد المرتبات — إيجيترانس نوسكو

أداة داخلية لحساب صافي المرتب والمكافآت والـ Gross-Up، مطابقة لطريقة التسوية التراكمية (YTD) المتبعة في منظومة الضرائب الموحدة المصرية.

## المميزات

- **المرتب الشهري:** حساب الصافي من الإجمالي، أو Gross-Up (الإجمالي من الصافي).
- **المكافآت:** حساب صافي المكافأة أو الـ Gross-Up بتسوية ضريبية كاملة من أول السنة (YTD).
- إدخال شهر صرف المكافأة، وحصة التأمينات يدوياً، والمكافآت السابقة هذا العام.
- بنود إضافية: استحقاقات داخلة في الوعاء الضريبي / استقطاعات تُخصم منه.

## النشر على Cloudflare Pages

### الطريقة الأسرع (رفع مباشر — Direct Upload)
1. ادخل على **Cloudflare Dashboard ← Workers & Pages ← Create ← Pages ← Upload assets**.
2. ارفع محتويات مجلد `payroll_site` (مش المجلد نفسه — المحتويات).
3. اختار اسم للمشروع واضغط **Deploy**.

### عبر GitHub (للتحديثات التلقائية)
1. ارفع المجلد على repo في GitHub.
2. في Cloudflare Pages: **Connect to Git** واختار الـ repo.
3. الإعدادات:
   - **Build command:** اتركه فارغاً
   - **Build output directory:** `/` (أو `payroll_site` لو رفعته كمجلد فرعي)
4. **Save and Deploy**.

> الموقع ثابت بالكامل (Static) — مفيش build step، مفيش backend، مفيش API. كل الحسابات بتتم في المتصفح.

## ملاحظات مهمة للصيانة

- **حدود التأمينات:** الحد الأقصى والأدنى للأجر التأميني موجودين في أول `app.js` في الكائن `INS`:
  ```js
  const INS = { rate:0.11, min:2700, max:16700 };
  ```
  القيم الحالية مطابقة لقرار الهيئة القومية للتأمين الاجتماعي الساري من 1 يناير 2026 (الحد الأدنى 2,700 — الحد الأقصى 16,700). لو تغيرت الحدود لسنة جديدة، عدّل القيم دي فقط.
- النتائج **تقديرية** كمساعِد حسابي. المطابقة النهائية لازم تتم مع منظومة مصلحة الضرائب قبل الصرف، لأن البنود الفعلية لكل موظف قد تختلف.
